# 微调全流程详解（SparkPro + LoRA）

本项目以星火大模型 **SparkPro** 为基座，采用 **LoRA 低秩适配** 做有监督微调（SFT），用金融指令集强化领域专业性与「投资」语义捕捉，同时控制成本（LoRA 参数量 < 原模型 1%，显存门槛低、可热插拔）。

---

## 一、数据集

| 数据集 | 规模 | 类型 | 用途 |
|--------|------|------|------|
| **FinCUGE-Instruction** | 训练 123,137 + 评测 15,167 = **138,304** | 金融通用理解指令（Apache-2.0） | 训练主集，覆盖 FINFE 等数十类任务 |
| **DISC-Fin-SFT** | **400** | 金融指令（计算/咨询/检索/任务四类，指令-输入-输出配对） | 补充专业场景 |
| **FinEval** | **4,661** 道多选一 · 34 个金融科目（上财） | 金融知识评测基准 | 评测 |

**示例**（FinCUGE 训练样本）：
```
task: 金融情感分析
instruction: 判断下列新闻对贵州茅台股价的影响倾向
input: 茅台披露年度分红预案，每股派现 30.876 元
output: 正面
```

**示例**（DISC-Fin-SFT 计算类样本）：
```
instruction: 计算某股票三年年化收益率
input: 期初净值 1.0，三年后净值 1.45
output: (1.45/1.0)^(1/3)-1 ≈ 13.5%
```

**示例**（FinEval 评测题）：
```
题：下列货币政策工具中，属于数量型工具的是？
A. 存款准备金率  B. 再贴现利率  C. 公开市场操作利率  D. 窗口指导
答案：A
解析：存款准备金率直接调节货币供应量，属典型数量型工具……
```

## 二、训练流程

### Step 1 · 数据集准备
合并训练集：FinCUGE（13.8 万通用指令）为主 + DISC-Fin-SFT（400 专业场景）做领域增强；FinEval 仅作评测，不进训练。

**示例**（混合后一条训练记录）：
```
{"instruction": "对比红利策略与成长策略的风险收益特征",
 "input": "",
 "output": "红利策略……低波动、高股息、防御性强；成长策略……高弹性、波动大……"}
```

### Step 2 · 任务设计（SFT）
监督微调目标：强化「投资」语义捕捉 + 金融专业口吻 + 合规风险提示（不荐具体买卖、强调风险自负）。

### Step 3 · 训练配置（LoRA）
冻结原基座权重，仅训练注入的低秩矩阵（A、B），显存占用大幅下降。

**示例**（配置）：
```python
base_model    = "SparkPro"        # 星火大模型基座
method        = "LoRA"           # 低秩适配，冻结原权重
lora_r, lora_alpha = 16, 32       # 低秩维度 / 缩放系数
learning_rate = 8e-5
epochs        = 5
train_data    = ["FinCUGE-Instruction", "DISC-Fin-SFT"]
eval_data     = "FinEval"         # 金融多选一评测（34 科目）
```

### Step 4 · 训练执行
LoRA 参数量 < 原模型 1%，单卡即可训练，多个 LoRA 适配器可热插拔切换。

**示例**（训练日志片段）：
```
epoch 1/5  loss=0.412  lr=8.0e-05
epoch 3/5  loss=0.218
epoch 5/5  loss=0.159  eval_acc=0.685
```

### Step 5 · 评测
- **自动评测**：FinEval 34 科目多选一准确率。
- **三层人工/AI 评测**：AI Judge（专业性）、AI as Customers（用户体验）、人工抽检。
- **消融实验**：对比「仅 FinCUGE」vs「+DISC」对荐股/咨询任务的影响。

**示例**（效果对比）：
```
FinEval 准确率：基座 61.2%  →  微调后 68.5%（+7.3pt）
咨询任务人工评分：4.1/5  →  4.6/5
```

## 三、关键设计点
- **知识-能力解耦**：通用金融知识放进 RAG 知识库（实时、可更新），「投资」语义与口吻靠微调内化——避免灾难性遗忘、降低幻觉。
- **LoRA 而非全量微调**：成本可控、可多任务热插拔；如需更强专业性可上调 `lora_r` 或叠加 QLoRA（4-bit 量化）。
- **数据质量 > 数量**：400 条高质量 DISC 专业样本即可明显拉升领域表现，远胜堆量。
- **评测闭环**：FinEval 量化 + 三层主观评测，确保上线即达标。
