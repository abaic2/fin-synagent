# Screen 荐股数据 · 候选池与四维特征

> **文档类型**：技能参考文档（reference）
> **所属技能**：Fin Synagent · 多智能体协同智能投顾
> **关联模块**：Screen 智能荐股（筛选树六步中的股票池、四维特征、LLM 评分）
> **适用行业**：白酒 / 红利 / 贵金属（各 5 支候选池）
> **何时引用**：执行荐股六步法的「股票池构建」「四维特征」「LLM 评分」「Top-3 推荐」时取本文件数据

## 一、文档用途

本文件是 Screen 智能荐股的**数据底座**。覆盖每个行业 5 支候选标的的基本面、技术面、情绪面原始数据，以及资深分析师 LLM 评分（0-100）与 Top-3 推荐理由。数据来源于 qstock 行情/财报接口，情绪面为 FinBERT 三分类（正面/负面/中性概率），均为演示用模拟数据。

## 二、荐股流程与字段说明

流程：用户偏好 → 条件解析（JSON `{sector, risk, objective}`）→ 股票池构建（行业过滤 + 市值>500 亿 + 非 ST）→ 四维特征 → LLM 评分（0-100）→ 排序 TopK → 推荐解释。

表格字段：PE/PB/ROE%/营收增速%（基本面）、趋势/均线/波动率/MACD（技术面）、情绪（正/负/中概率，情绪面）、评分（LLM 综合，0-100）。
